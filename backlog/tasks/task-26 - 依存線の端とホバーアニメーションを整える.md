## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
曲線化した依存線は起点が角張り、ホバー時の破線アニメーションが意図する流れと違う。依存方向を追いやすくしつつ、線の表現を調整しやすくする。
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 依存線の起点が丸く表示され、矢印の先端形状は維持される
- [x] #2 通常時・強調時とも2pxの線幅をコード内の定数で管理する
- [x] #3 ホバーしたエッジまたはノードに関連する全依存線で、直径5px・線と同色の円が約120px間隔、約80px/秒で起点から先端へ動く
- [x] #4 円は端で自然に出入りし、動きを減らす設定では消える一方、関連線の強調は残る
- [x] #5 ノードを選択している間はホバーがなくても関連する全依存線で円が動き、別のエッジやノードをホバーしている間はホバー先の強調が優先される
- [x] #6 1,000ファイル・3,000辺・41ディレクトリのgrouped描画測定で選択・テーマ切替・ホバーが300ms以内となり、非関連線の矢印と変更ラベルも薄く表示される
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. 依存線の線幅を定数にし、SVGの線端を丸くする。
2. 曲線の上に、丸い線端を持つ長さ0の描画点を約120px間隔で置き、約80px/秒で移動させる。SVGマスクで両端約10pxをフェードし、動きを減らす設定では点を非表示にする。
3. 実ブラウザーで表示・ホバー・移動・色・フェード・動きの抑制を確認し、型・lint・整形・全テスト・描画性能・配布検証を行う。

4. 選択中の関連線にも円を表示し、ホバーへの切替と選択解除をブラウザーで検証する。

5. 高密度グラフの性能未達を修正する。SVGグループ全体のopacityを廃止し、線・矢印・ラベルを個別に薄くする。円・フェード・発光・300ms目標は維持する。

6. 追加・削除線を含むブラウザー回帰検証とスクリーンショット確認を行い、groupedの繰り返し測定、layered・hub、必須品質チェックで確認する。
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
当初は円ごとにSVGアニメーション要素を生成したが、999本が1ノードにつながる条件で大量の要素が発生した。丸い線端を持つ長さ0の描画点を1本のSVGパスで繰り返す方式に変更し、全線アニメーションを維持した。

検証: 実ブラウザーで通常2px・強調3px・丸い線端・矢印マーカー、同色/直径5px/120px間隔/1.5秒周期の点、移動量、両端のSVGフェードマスク、動きを減らす設定での非表示と強調維持を確認。ノードホバー時は関連する全辺（999辺のhubを含む）に点を表示した。1000ファイル/3000辺の通常形状では初期描画約727ms・ノードホバー約83ms・エッジホバー約81msで目標内。1000ファイル/999辺のhubでもノードホバー約70ms、エッジホバー約32msで通過した再測定あり。hubの別測定ではテーマ切替が363msとなり300ms目標を超過したが再測定では289ms。1000ファイル/41ディレクトリの既知の高密度条件はテーマ切替396msで目標超過。pnpm test 129件、typecheck、lint、format:check、benchmark:layout 1000、test:pack、backlog doctor、git diff --check 成功。

表示を試した結果、円の直径は5pxを維持し、強調時の線幅は通常時と同じ2pxへ調整した。40ファイルの実ブラウザーで見た目・ホバー・移動・動きを減らす設定を再確認し、描画ベンチマーク、整形確認、git diff --check が成功した。

追加検証: 選択したファイルの全関連辺にホバーなしで円が表示されることをブラウザー測定で確認。ホバー時はその対象の辺だけが動き、1,000ファイル/3,000辺でも選択・ホバー操作が300ms目標内。pnpm test 129件、typecheck、lint、format:check、benchmark:layout 1000、test:pack、backlog doctor、git diff --check 成功。

PR #13のgrouped未達を修正。グループopacityを廃止し、線と矢印を同じ12%アルファ色、ラベルと背景をfill-opacityで薄くする。仕様・性能閾値は維持するが、重なりは要素ごとのアルファ合成になる。groupedの3回測定は選択最大121.8ms・テーマ切替50.2ms・ノードホバー75.6ms・エッジホバー67msで成功。layeredも成功。追加・削除線を含む両テーマの色・矢印・ラベル・破線・ホバー解除をブラウザー回帰検証し、画像と生測定値をdoc-4に記録。hubは修正後1,432ms、変更前HEADでも1,387msの選択遅延が再現するため別の残存問題として明記する。全129テスト・型・lint・整形・配置2条件・配布検証成功。
