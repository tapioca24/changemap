## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
依存関係グラフが画面に対して小さく、主要な情報を確認しづらい。ヘッダーの下をグラフ中心の広いキャンバスと右側の差分コードペインに分け、レビュー対象を見渡しやすくする。キャンバス上のリフレッシュ操作と、依存範囲外として解析されたファイルの縦方向の配置も扱う。

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. 合意したグラフ中心の全高レイアウト、コンパクトな比較情報、キャンバス内の操作と警告詳細を実装する。
2. 未選択時は閉じる右ペインを実装する。初期幅30%、最大50%、ドラッグとキーボードで調整し、幅と対象外一覧の開閉をブラウザに保存する。
3. 対象外ファイルを左の折りたためる縦一覧にする。狭い画面ではグラフと差分を切り替え、表示状態を維持する。
4. ペイン開閉・リサイズ後に選択ノードが隠れた場合のみ、倍率を維持してアニメーションで補正する。ドラッグ中は補正しない。更新後も対象が残れば選択と表示位置を維持する。
5. 回帰テスト、実ブラウザ検証とスクリーンショット、型検査・lint・整形・全テスト・レイアウト検証・配布検証を行う。

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
実装: Workspace に全高レイアウトとペイン開閉・リサイズを分離。幅は初期30%・最大50%・最低320px、960px未満は切り替え表示。対象外ファイルは左の独立スクロール一覧。幅と開閉状態は起動時のポート変更にも対応するブラウザCookieに保存（機密情報なし）。解析警告の詳細は初期状態で折りたたむ。
位置補正: React FlowのsetViewportを240ms・linear補間で使用し、移動途中の倍率変化も防ぐ。reduced-motion時はアニメーションなし。ドラッグ中は補正を停止。更新後のファイルはbefore/afterのパスで追跡する。
検証: pnpm test は最終ビルドで106件成功。pnpm typecheck / lint / format:check / git diff --check 成功。pnpm benchmark:layout 1000 は1000ノード・3000エッジ、約1.23秒。pnpm test:pack は隔離環境で成功。再テスト時のポート待受EPERMはサンドボックス制限であり、許可された制限外実行で全件成功。
実ブラウザ: 1440x900で初期幅432px、キャンバス高さ687px。ドラッグ中のtransform不変を確認。補正アニメーション15フレームすべて同倍率を確認。ポート65250→50233で幅の復元を確認。リフレッシュ前後のtransformと選択保持を確認。390x844で差分を全幅表示し、戻る操作後も同一グラフDOMと選択を保持。画面全体の横・縦はみ出しなし、ブラウザ実行エラーなし。
参考のアクセシビリティ監査では既存の全文コード行番号にコントラスト不足が検出された。今回のレイアウト変更範囲では色を変更していない。
